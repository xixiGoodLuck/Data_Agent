# DeepSeek 中英文 40 条优化复测

[**简体中文**](deepseek-bilingual-40-optimization-report.md) | [English](deepseek-bilingual-40-optimization-report.en.md)

评测完成时间：`2026-07-13`。本报告比较同一组 20 条中文问题与 20 条英文问题在优化前后的表现。四套固定快照分别为 USGS 近 30 天地震、NOAA JFK 2025 日气象、World Bank 2015-2024 国家指标和中国国家统计局 2024 省级指标。

标准答案全部由独立 SQLite oracle SQL 计算，DeepSeek 不参与生成标准答案。结果比较允许数值绝对误差 `0.02`，同时检查行顺序、类别标签、查询状态和预期图表类型。

## 如何优化

1. **隔离问题上下文**：每条真实数据问题使用新会话；问题改写器只在代词或“同一组”等明确引用出现时读取历史，独立问题不再继承上一条的筛选、时间范围和排名条件。
2. **固定快照语义**：SQL prompt 现在接收数据集标识。若 `_30d` 等标识已经定义快照窗口，问题再次提到“近 30 天”时禁止用 `date('now')`、`datetime('now')` 或 `CURRENT_DATE` 重新裁剪快照。
3. **稳定输出契约**：只投影问题要求的维度和指标；时间桶统一为 ISO `YYYY-MM`/`YYYY-MM-DD`；SQL 别名和类别标签统一使用 ASCII 小写 snake_case。
4. **聚合与分箱契约**：未指定排序的分组比较优先按计数降序；相邻数值区间采用半开区间；分箱标签由边界稳定生成，例如 `under_10_km`、`10_50_km`、`100_km_or_more`。
5. **双期变化输出**：prompt 要求用单行条件聚合并禁止会触发行级风险的 self-join。最终英文用例仍由模型选择了标量子查询，但只返回变化量和变化率，风险评估为低并通过 oracle；这也说明 prompt 是约束信号，不是安全边界。
6. **确定性图表规划**：单行多指标聚合使用 number；带多个描述维度或三个以上指标的结果使用 table；真正的日期排名使用 table；月度趋势使用 line。中文“平均最高/最低气温”不再被误判为排名。
7. **安全边界不变**：所有模型 SQL 仍先经过 `sqlglot` 白名单验证，再在选中数据集的 SQLite 只读连接中执行；没有为了提高通过率放宽审批或只读策略。

## 运行与选择规则

- 首轮按中文 20 条、英文 20 条顺序执行，每个问题使用独立会话。
- 首轮优化得到 82.5% 结果准确率和 95.0% 图表准确率后，只重跑 8 个受影响问题，共产生 48 个有效 case attempt。
- 最终 40 条按“每个语言/数据集/问题选择最新 attempt”计分；JSON 为每条记录保留 `attempt_count` 和 `superseded_query_log_ids`，没有隐藏被替换试次。
- 应用中的一次性 Key 仅存在于页面内存。运行后已刷新页面，并确认 Settings 显示 `Not set`；报告和仓库扫描未发现 Key。

## 限制

`100%` 只表示该模型、该代码版本、这四个固定数据快照和这 40 个预先定义问题的最新试次全部通过，不代表任意自然语言问题都能达到 100%。真实模型输出具有非确定性；后续应继续扩大同义改写、复杂 join、空值、并列排名和对抗性语义用例，并将多次重复运行的方差纳入报告。
